# Dr Rakesh Parikh — Static Blog Migration

This is the first migration pass from the WordPress WXR export.

## Included
- Published posts converted to Markdown
- Original titles, dates, slugs, categories and tags
- Original URLs retained in frontmatter
- Legacy image tags removed because the old uploads directory was unavailable
- YouTube embeds converted to simple video references
- A minimal Astro project scaffold

## Not yet included
- Final visual design
- Navigation/search
- Image replacement
- SEO/social metadata refinement
- Redirect rules
- Final editorial modernization

## Next step
Review a small sample of migrated Markdown files, then refine the conversion rules before deploying the complete site.

## Personal vs professional identity
The homepage and article pages clearly identify this domain as a personal blog archive and provide a link to the author's professional website, Diabecity (`https://diabecity.co.in`).

## Visual direction
The homepage now presents the site as a personal writing archive rather than a news or professional practice site. The professional bridge to Diabecity remains visible but secondary.
